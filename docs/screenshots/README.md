# Screenshots

Drop screenshot/GIF files here using the exact filenames below, then they will
appear automatically in the main [README](../../README.md) "Screenshots" section.

| Filename | What to capture |
|---|---|
| `hero.png` | Landing page — the URL input / hero section |
| `analysis.png` | A video result page — summary, chapters, key takeaways |
| `quiz.png` | The interactive quiz in progress |
| `flashcards.png` | Flashcard study mode (or the SRS review page + retention chart) |
| `mindmap.png` | The mind map or knowledge graph view |
| `dashboard.png` | The dashboard — streak, stats, quiz history |

## Tips for good screenshots

- Use a clean browser window (hide bookmarks bar, use an incognito window).
- Capture at a consistent width (~1280px) so they line up nicely.
- For the mind map / knowledge graph, a short **GIF** (e.g. via ScreenToGif or
  macOS screen recording → convert) shows interactivity well — save as
  `mindmap.gif` and update the link in the README if you go that route.
- Keep each image under ~1 MB so the repo stays light (PNG optimized, or JPG).

## Naming

Stick to the filenames in the table above — the README already references them.
If you add extra shots, name them `extra-<topic>.png` and add them to the
README's Screenshots section manually.
